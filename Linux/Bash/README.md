## Bash

Bash - это консоль (CLI) и скриптовый ЯЗ

---
### Управление Терминалом (консолью)

Сдвинуть лог вверх
`Ctrl+L`

Очистить экран
`clear`

Получить историю
```shell
history
```

Перелистывание ранее введённых команд
`Стрелка вверх/Стрелка вниз`

Выполнить последнюю (из списка history) команду
```shell
!!
```

Выполнить указанную команду из списка history
```shell
!45
```
где `45` это порядковый № команда из history

Остановить запущенный в консоле процесс по `Ctrl+C`

### Файловые операции

Получить структуру каталогов и файлов 
```shell
tree
```

получить абсолютный путь к текущему каталогу
```shell
pwd
```
показать содержимое текущего каталога
```shell
ls
```
показать содержимое всего

```shell
ls -all
```
или показать содержимое указаной папки
```shell
ls Dir_name
```
где `Dir_name` - это имя нужной папки

Правила именования каталогов и файлов:
1. Только по-английском
1. Без пробелов и спец.символов
1. Если имя файла или каталога состоит из нескольких англ. слов., то имя можно создать так: `firstOFall` или `first_of_all`
1. В имени файлов лучше всегда указывать расширение `filename.txt`

Выйти из текущей папки
```shell
cd ..
```

Вернуться в предыдущую папку
```shell
cd -
```

Зайти в указанную папку
```shell
cd TargetForder
```
---

Знаки:

`\` - Обратный слэш - признак каталога
`/` - Прямой слэш - признак каталога
`|` - Вертикальный слэш - признак разделения команд

---

Windows:
`\` - корневой каталог
Unix/Linux/Android/MacOS,IOS,BSD:
`/` - корневой каталог

Выйти из текущего каталога на 2 шага вверх:
```shell
cd ../..
```

#### Создание файлов и каталогов

Создание файлов
```shell
touch file_name.txt
```
редактировать текстовый файл
```shell
micro file_name.txt
```

- `micro` - текстовый редактор командной строки
- Сохранить по `Ctrl+S` и выйти из редактора по `Ctrl+Q`

Переименовать файл
```shell
mv old_name new_name
```

копирование файл
```shell
cp name_file.txt NewFolder/
```
переместить файл
```shell
mv file.txt TargetName
```

Удалить файл
```shell
rm delFile.txt
```

Удалить папку
```shell
rm -rf DelFolder
```

Создать несколько файлов
```shell
touch {1...3}.txt
```

Создать несколько каталогов
```shell
mkdir folderName{1..4}
```

Удалить содержимое текущего каталога
```shell
rm -rf *
```

Создать структуру проекта:
```
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```

Создать такую структуру одной командой:
```shell
mkdir -p project/{css,js,img/ico,fonts,pages}
```

### Linux

```shell
hostname
```

Локальный ip
```shell
hostname -i
```

сетевая информация
```shell
ifconfig
```
или
```shell
ip -c r
```
или подробно
```shell
ip -c a
```
Пинг
```shell
ping ya.ru
```
или определённое кол-во раз
```shell
ping -c 4 ya.ru
```
Получить ин-фу по домену
```shell
whois ozon.ru
```

Получить порты
```shell
netstat -an
```

Получить маршруты
```shell
route
```

Выйти из сеанса пользователя

```shell
exit
```
перезагрузить



Получить текущее время
