# Самостоятельная работа по Bash программированию

Репозиторий с набором учебных Bash-скриптов.

## 📋 Список скриптов

| Файл | Описание |
|------|----------|
| `1.sh` | Спрашивает имя пользователя и выводит приветствие |
| `2.sh` | Калькулятор суммы двух чисел |
| `3.sh` | Проверяет, является ли число чётным или нечётным |
| `4.sh` | Создаёт структуру папок для веб-проекта (`index.html`, `css/`, `js/`) |
| `5.sh` | Подсчитывает количество строк в указанном файле |
| `6.sh` | Генерирует случайный пароль длиной 8 символов |
| `7.sh` | Ищет файлы по расширению в текущей директории |
| `github-stats.sh` | Анализатор репозиториев GitHub с цветным выводом статистики (без jq, только curl/grep/sed) |
| `gitflic-stats.sh` | Анализатор репозиториев GitFlic с цветным выводом статистики (без jq, только curl/grep/sed) |

## ▶️ Как запускать

Все скрипты нужно выполнять через **Git-Bash** (не PowerShell):

```bash
sh 1.sh
sh 2.sh
# и т.д.
```

Перед запуском можно выдать права на выполнение:

```bash
chmod +x *.sh
./1.sh
```

## 🚀 github-stats.sh

Скрипт анализирует репозиторий на GitHub через публичный REST API.

**Требования:** только `curl` — предустановлен почти везде (Ubuntu WSL, Git-Bash),
JSON разбирается вручную через `grep`/`sed`, `jq` ставить не нужно.

```bash
./github-stats.sh tensorflow/tensorflow
```

Выводит название, количество звёзд (жёлтым), форков (зелёным), открытых issues
(красным, если больше 100, иначе жёлтым), автора и дату последнего обновления.
Обрабатывает ошибки: отсутствие `curl`, неверное имя репозитория, превышение
лимита запросов к API. Поля GitHub API (`stargazers_count`, `forks_count` и т.д.)
официально задокументированы, поэтому парсинг стабилен без дополнительных проверок.

## 🚀 gitflic-stats.sh

Скрипт анализирует репозиторий на GitFlic через REST API (`https://api.gitflic.ru`).

**Требования:** только `curl` — JSON разбирается вручную через `grep`/`sed`, без `jq`.

```bash
./gitflic-stats.sh SantaSpeen/gitflic
```

Выводит название, описание, количество звёзд (жёлтым), форков (зелёным) и открытых
issues (красным, если больше 100, иначе жёлтым). Обрабатывает ошибки: отсутствие
`curl`, неверное имя репозитория, превышение лимита запросов.

> ⚠️ Официальная документация API GitFlic (`gitflic.ru/help/api/intro`) не отдаёт
> точную схему JSON-ответа в открытом виде. Скрипт ищет значения по нескольким
> вероятным названиям полей (`starCount`, `star_count`, `stars` и т.д.). Если после
> запуска какие-то значения выводятся как `0`, выполните `curl -s https://api.gitflic.ru/project/owner/repo`
> вручную, посмотрите реальные имена полей в ответе и добавьте их в список внутри
> функции `extract_field` в скрипте.
