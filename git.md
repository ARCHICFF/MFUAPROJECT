## Основы Git?

### Зачем Git?

#### Почему не флешка?

1. Флешка - потенциальный разносчик вирусов.
1. Ваши личные данные могут случайно попасть на чужой компьютер.
1. Антивирус может удалить ваши файлы с флешки
1. Флешка может случайно потеряться или сломаться

#### Почему не Yandex или Google диск?

1. Облако Yandex или Google диск не контролирует версии файлов.
1. Ваши данные к Yandex или Google могут случайно остаться на чужом компьютере.

### Преимущества Git

1. Трудно потерять свои проекты.
1. Легко отслеживать версии ваших проектов.
1. Легко делиться с другими людьми вашими проектами.
1. Легко вести совместную работу над одним проектом.
1. Git -де-факто стандарт и интегрирован почти по все современные технологии IT (например в VS Code etc.).
1. В Git можно создавать веб-страницы как хостинге.
1. Git-сервисы дают возможность автоматизировать сборки и тестирование ваших приложений.

### Основные состаяния Git-репозитория

1. **Инциализация** - `git status` - показывает текущее состояние репозитория.
1. **Подготовка** - `git add .` - подготовка (добавление) изменений.
1. **Фиксация** - `git commit -m "some message"`
1. **Синхранизация** - удалённой копией текущего репозитория - `git push`и`git pull`"`

### Что можно сохранять в Git?

1. Любые текстовые файлы, объемом < ~ 40 mb.
1. Изображения, документы, mp3, PDF, короткие видио и т.д.
1. Все имена файлов

### Основные команды Git.

Получить версию устанного Git:
```shell
git --version
```

Получить справку
``` shell
git help
```

**Сменить текстовый редактор по умолчанию**
На `Micro` (проще для новичка)
```shell
git config --global core.editor "micro"
```
На `Nano` (чуть сложнее для новичков)
```shell
git config --global core.editor "nano"
```
На `VS Code` (элементарен для новичков)
```shell
git config --global core.editor "code --wait"
```

**Представиться сестеме Git**
Сообщить свой никнейм
```shell
git config --global user.name "Fixic"
```

Сообщить свой эмэйл
```shell
git config --global user.email "my_email@mail.ru"
```

>**Если вы на чужом компьютере, то вместо `--global` используйте `--local`**

### Клонировать репозиторий
```shell
git clone https://gitflic.ru/project/rurewa/mfua.git
```
Открыть папку клонированного репозитория
```shell
cd folder_name
```
Получить статус текущего репозитория
```shell
git status
```

Получил состояние удалённого репозитория
```shell
git remote show origin
```
Получить локальные ветки текущего репозитория
```shell
git branch
```
```shell
git remote --v
```
